# GameData

This folder is a placeholder. **No game file is ever stored in this repository.**

- Game data is supplied by the user from their own licensed installation.
- The original installation is treated as read-only. Tools in `Tools/` open files in read
  mode and never write inside the game folder.
- Do not copy executables, bundles, audio, video or any other game content here, and do not
  attach them to issues, commits or releases.
- `.gitignore` blocks common game file types as a safety net.
